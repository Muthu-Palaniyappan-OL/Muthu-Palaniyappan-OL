Building My Personal Site with Tailwind

I recently rebuilt my personal website using plain HTML and Tailwind CSS v4, deployed on Cloudflare Pages.

The stack is minimal — Vite for bundling, Tailwind for styling. No heavy frameworks, no SSR complexity. Just a fast static site that loads in milliseconds.

Tailwind v4 with the Vite plugin makes the DX smooth — no config file needed, just @import "tailwindcss" and you're good to go.

The whole thing deploys automatically via GitHub Actions to Cloudflare Pages on every push to main. Simple, fast, free.
